# Proposed Discussion insertion

Insertion point: after the Discussion paragraph beginning "The regret constraint changes the scientific meaning of representative locking."

> The formal guarantee is deliberately narrow: regret-constrained locking returns a supplied candidate whose configured empirical development-CV score gap does not exceed \(\delta\), and canonical content-derived ordering makes the selected feature set reproducible under candidate-record permutations. The stable hash supplies ordering rather than evidence, and duplicate-run multiplicity remains part of the candidate bank.
